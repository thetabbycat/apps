# VibeCleaner - Support

Thank you for using VibeCleaner! This document provides guidance on how to report issues, request features, and get help.

## Before You File an Issue

Xcode Source Editor Extensions can sometimes be tricky to enable. If the commands are not appearing in the **Editor** menu, please ensure you have completed the following steps first:

1.  **Run the Main App:** After installing, did you launch **VibeCleaner.app** from your `/Applications` folder at least once? This is a required step to register the extension with macOS.
2.  **Enable the Extension:** Have you enabled **"VibeCleaner"** in **System Settings > Extensions > Xcode Source Editor**?
3.  **Restart Xcode:** Have you completely quit Xcode ( `Cmd + Q` ) and restarted it after enabling the extension? A simple restart often resolves visibility issues.
4.  **Check Target:** The commands only work on source code files. Ensure you have a Swift, Objective-C, or other source file open and active in the editor.

If you've done all of the above and are still experiencing issues, we'd love to help.

## How to Report a Bug

Bugs are best reported via **GitHub Issues**. Please follow these steps to create a helpful bug report:

1.  **Check for Duplicates:** Before creating a new issue, please [search existing issues](https://github.com/stevenselcuk/VibeCleaner/issues) to see if your problem has already been reported.
2.  **Create a New Issue:** If no existing issue describes your problem, please [create a new one](https://github.com/stevenselcuk/VibeCleaner/issues/new).

Please include the following information in your bug report:

*   **A clear and descriptive title.** (e.g., "Clean Comments command crashes on Objective-C files.")
*   **Your Environment:** Your macOS version and Xcode version.
*   **Steps to Reproduce:** Provide a clear, step-by-step description of how to trigger the bug.
*   **Example Code:** If possible, include a small code snippet that causes the issue.
*   **Expected vs. Actual Behavior:** What did you expect to happen, and what actually happened?

## How to Request a Feature

We welcome ideas for new features or improvements! Please use **GitHub Issues** to submit your suggestions.

1.  **Check for Duplicates:** [Search existing issues](https://github.com/stevenselcuk/VibeCleaner/issues) to see if someone else has already suggested your idea.
2.  **Create a New Issue:** If your idea is new, [create a new issue](https://github.com/stevenselcuk/VibeCleaner/issues/new) and describe your feature request in detail. Explain the problem you're trying to solve and how your proposed feature would help.

By channeling support through GitHub Issues, we can track all feedback in one place and work more efficiently. Thank you for your contribution
